# 🧠 AI Summarizer Chrome Extension

A lightweight Chrome Extension built with **JavaScript** and **Gemini API** to summarize web content using AI. Users can choose from multiple summary styles (brief, detailed, bullet points) and copy results with a single click.

---

## 🚀 Features

- 🔍 Extracts readable text from any active tab.
- 🤖 Summarizes using Google's Gemini 1.5 Flash API.
- 📝 Options for brief, detailed, or bullet point summaries.
- 📋 One-click copy to clipboard.
- 💡 Simple, clean UI.

---

## 🛠️ Technologies Used

- **JavaScript**
- **Chrome Extension APIs**
- **Gemini 1.5 Flash API**
- Basic **HTML/CSS**
